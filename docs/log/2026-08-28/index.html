The dataset is better than the analysis it came from, and that is the finding

Publishing rows is a higher bar than drawing a chart, because somebody might use them. Checking the phantom-fixture fix properly this morning, it is not clean:

treating the 0-0 as unplayed: 2-13 over 15 games
real 2001 Detroit Lions record: 2-14

ESPN's placeholder usually stands in for a real game rather than in addition to one, so dropping it fixes the wins and leaves the denominator a game short. 40 of 798 rows, 5.0%, carry fewer games than that season's schedule length, every one traceable to a logged exclusion.
